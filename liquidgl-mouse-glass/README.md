# Liquid Glass Effect with liquidGL

This project implements a liquid glass effect that follows the mouse cursor using the liquidGL library. The effect creates a visually appealing glass-like interface that dynamically responds to user interactions.

## Project Structure

```
liquidgl-mouse-glass
├── src
│   ├── index.html        # HTML structure for the project
│   ├── main.js           # JavaScript code for initializing liquidGL
│   └── styles.css        # CSS styles for the glass effect
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Davdadev/davidsebbag.git
   cd liquidgl-mouse-glass
   ```

2. **Install Dependencies**
   Make sure you have Node.js installed. Then run:
   ```bash
   npm install
   ```

3. **Run the Project**
   Open `src/index.html` in your web browser to see the liquid glass effect in action.

## Usage

- Move your mouse around the screen to see the glass effect follow your cursor.
- The content inside the glass pane will be dynamically refracted, creating an interactive experience.

## About liquidGL

The liquidGL library is a powerful tool for creating liquid-like effects in web applications. It allows for real-time rendering and manipulation of visual elements, making it ideal for creating engaging user interfaces.
